# IEEE report source

`main.tex` is the project report written with the IEEE conference template (`IEEEtran`). The compiled PDF is `IEEE_Report_Final.pdf`.

| # | Section |
|---|---|
| - | Abstract and Index Terms |
| I | Introduction |
| II | Literature Review |
| III | Proposed Solution (architecture, address fields, request flow, FSM, timing, tool flow) |
| IV | Implementation and Verification |
| V | Results and Discussion (waveforms, performance, synthesis) |
| VI | Individual Contributions |
| VII | Conclusion and Future Work |
| - | References |

Build: `make report` from the repository root (or `pdflatex main.tex` three times in this folder). Install the class once with
`tlmgr --usermode install ieeetran`. The figures in `figures/` are generated by `make diagrams`, `make waveforms` and `make perf`;
the text and tables use the numbers from `docs/perf_results.md`, `docs/verification.md` and `synth/SUMMARY.md`.
Fill in the team names on the title page and in the Individual Contributions table before submitting.
